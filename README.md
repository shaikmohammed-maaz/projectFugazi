# NexCoin Landing Page

This project is a modern React-based landing page for NexCoin, a secure, sustainable, and mobile-first cryptocurrency. Built with Vite for fast development and CSS Modules for modular, maintainable styling.

## Features
- Responsive, mobile-friendly design
- Modular React components
- Styled with CSS Modules
- Ready for future feature development

## Getting Started

1. **Install dependencies:**
   ```powershell
   npm install
   ```
2. **Start the development server:**
   ```powershell
   npm run dev
   ```
3. Open your browser and visit the local address shown in the terminal (usually http://localhost:5173).

## Project Structure
- `src/NexCoinLanding.jsx` – Main landing page component
- `src/NexCoinLanding.module.css` – CSS Module for landing page styling
- `src/App.jsx` – App entry, renders the landing page

## Customization
- Replace placeholder icons, links, and images as needed
- Extend components for new features
